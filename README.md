# SpiceUp-DDOS_Guard-Desktop2Proxy
Краткая инструкция по использованию OmniLink Network Connector

   Запуск приложения
   
      bash
      python omnilink_network.py


   Основные функции

   1. Добавление устройств
- Нажмите кнопку "Добавить IP"
- Введите IP-адрес в формате XXX.XXX.XXX.XXX
- Устройство добавится в список для дальнейшего сканирования

   2. Сканирование сети
- "Сканировать все" - проверяет все добавленные устройства
- "Сканировать выбранное" - сканирует только выбранное устройство
- "Проверить сеть" - автоматически сканирует всю локальную сеть

   3. Подключение к устройствам
1. Выберите устройство из списка
2. Нажмите "Подключиться"
3. Введите логин и пароль
4. Приложение автоматически подключится через соответствующий протокол

   4. Поддерживаемые протоколы
- RDP (Remote Desktop) - для Windows систем
- SSH - для Linux/Unix систем
- VNC - для удаленного доступа
- HTTP/HTTPS - веб-интерфейсы
- FTP - файловые серверы

   Особенности работы

   Автоматическое определение:
- Операционной системы по баннеру служб
- Открытых портов и служб
- Типа устройства (сервер, сетевое оборудование и т.д.)

   Сохранение данных
Приложение автоматически сохраняет:
- Список обнаруженных устройств
- Результаты сканирования
- Историю подключений

Данные сохраняются в папке network_data в файле devices.json

   Советы по использованию
1. Перед подключением убедитесь, что устройство доступно (статус "Доступно")
2. Для точного определения ОС используйте повторное сканирование
3. При проблемах с подключением проверьте настройки брандмауэра
4. Используйте кнопку "Подробности" для получения полной информации об устройстве
